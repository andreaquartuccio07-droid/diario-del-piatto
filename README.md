# Diario del Piatto

App web da installare sul telefono per seguire una dieta di aumento massa: segna i pasti con un tocco, mostra quante calorie mancano e se sei indietro sulla tabella di marcia, propone ricariche veloci a fine giornata, registra il peso e calcola ritmo, arrivo stimato e mantenimento.

- Funziona anche senza campo (service worker).
- I dati (pasti e pesate) restano solo sul telefono: niente account, niente server.
- Su iPhone: apri il link in Safari → Condividi → "Aggiungi alla schermata Home".

Il menù (`dati.js`) è generato da un progetto separato: non modificarlo a mano.
